# Build and use

The normal macOS workflow does not require Terminal commands.

1. Download the repository ZIP from GitHub.
2. Unzip it.
3. Double-click Chrome-Patcher.app.
4. Choose Full Diagnostic for the complete read-only evidence bundle.
5. Choose Guarded Patch Check to see whether an approved patch exists.
6. Use Restore only when a verified patch backup exists.

Reports are saved under:

    ~/Desktop/chrome-patcher-baseline/

Python 3 is required. The app finds python3 automatically.
