# Chrome-Patcher

## Current diagnostic workflow

Phase 15 adds a compact Intel ANGLE/EGL diagnostic for the exact installed Chrome build.

On macOS, use the **Run Phase 15.command** launcher in this repository. It runs the focused read-only test and writes the concise report to:

    ~/Desktop/chrome-patcher-baseline/phase15/report.txt

No Chrome files are modified by Phase 15.
